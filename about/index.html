你好 👋，我是一名常驻上海的 搜索工程师 / 后端工程师，拥有 6+ 年的软件开发经验，主要关注搜索系统、信息检索以及数据密集型后端服务的设计与实现。

我的工作方向主要集中在 搜索与信息检索（Search & Information Retrieval），包括基于 Elasticsearch 的索引与检索、相关性优化、混合检索，以及大规模后端系统设计。日常主要使用 Java 和 Python，技术栈包括 Spring Boot、Elasticsearch、MySQL、Redis、Docker、Kubernetes，以及阿里云、AWS 等云平台。

同时，我也是一名 开源项目作者与维护者。目前在持续开发和维护 Anchr，这是一个面向文档理解与知识搜索场景的自托管项目，涉及文档解析、结构化索引、混合检索、Rerank、带引用的问答以及 Agentic RAG 等方向。相比单纯构建一个聊天机器人，我更关注如何把大模型能力真正融入搜索、检索和知识系统之中。

我尤其感兴趣的是 搜索、信息检索、LLM 与分布式系统的交叉领域：从传统的 BM25、向量检索，到 Hybrid Search、RAG，再到基于 Agent 的知识工作流。我喜欢把这些技术概念真正落地成可运行、可观测、可维护的工程系统。

工作之外，我也会持续折腾新的搜索与 AI 技术、维护开源项目，并记录一些实际开发过程中遇到的问题、思考和实践。

搜索，构建，持续探索。
