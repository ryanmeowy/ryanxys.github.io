长期焦虑之后，人为什么容易走向虚无或者及时享乐？

发表于 2024-04-07 分类于 个人思考

有一阵子，我常留意到身边人身上的一种变化：有些人明明一直很拼，却越来越觉得日子没意思；也有些人以前对未来满怀期待，在连着扛了几年高压之后，嘴边最常挂着的一句话变成了“算了”。

这种松劲儿，最后往往会滑向两个看着完全相反的方向。

一种是什么都瞧不上：“这么拼有什么用？就算混出头了又有什么意思？”另一种则是彻底倒向当下：“人生苦短，干嘛不先让自己痛快？”于是，吃顿好的、买心仪已久的东西、打游戏、刷剧、到处旅行，开始比那些遥不可及的规划诱人得多。

一个走向虚无，一个奔向享乐，看着南辕北辙，底子里的病因可能却是一样的：长期悬而未决的焦虑，把一个人对生活的掌控感慢慢磨光了。

我在这里聊的“虚无”，不是哲学书里那种宏大的虚无主义，就是我们日常突然觉得“一切都没劲”的瞬间。我更想理清楚的是：一个人到底是怎么从“我还想改写未来”，一步步退到“干什么都没意义”，或者“哪怕天塌下来，先爽了今天再说”的？

INTJ：用理性理解世界的人，也需要学会感受世界

发表于 2024-01-08 分类于 个人思考

刚接触 MBTI 那会儿，我并没有太当真。这类性格测试太容易给人一种幻觉：好像只要拿到了那四个字母，就能解释自己所有的怪癖，甚至提前看到后半生的剧本。

直到后来顺着往下摸，接触到“荣格八维”（认知功能），我才发觉这套东西真正有意思的地方，根本不是给你下定义，而是提供了一套拆解自己的词典。比如：为什么我总习惯把事情往后看三步？为什么遇到事的第一反应永远是找原因，而不是先发泄情绪？为什么别人转头就能翻篇的小插曲，我却要在脑子里反反复复推演好几遍？

当然，人没那么简单，四个字母不可能装得下成长环境、吃过的亏和走过的路。但在 INTJ 的功能拆解里，我确实照见了自己身上不少根深蒂固的习惯。

按常见的认知功能排序，INTJ 的底牌是这样打的：

  • 主导功能：内倾直觉（Ni）
  • 辅助功能：外倾思考（Te）
  • 第三功能：内倾情感（Fi）
  • 劣势功能：外倾感觉（Se）

我更愿意把这四行字当成一面镜子：Ni 负责在迷雾里摸索规律和远方，Te 负责挽起袖子把想法干出来，Fi 守着心底那套价值底线，而排在最末的 Se，则时不时敲打我别光顾着在脑子里跑模型，记得回真实世界喘口气。它不是用来给自己画地为牢的标签，却帮我看清了自己顺手的惯性，以及那些常年被我冷落的盲区。

线程明明空闲，任务为什么还是被拒绝了？

发表于 2023-05-16 分类于 故障日志

线上偶发 RejectedExecutionException 告警时，我的第一反应是先翻线程池配置：核心线程 32，最大线程 32，队列长度 16。业务侧是按批提交任务的，每批干完才会塞下一批。单看纸面数字，这个池子明明留着余量，按理说不该触发拒绝策略。

先把队列调大后，报错确实停了。但这种止血只能说明故障跟“瞬时容量”有关，并没能解释刚才到底发生了什么。等顺着源码把整个链路摸了一遍我才意识到，以前我对 corePoolSize + queueCapacity 的理解太静态了——它只代表池子在某一时刻最多能兜住多少在途任务，可没答应过每次批量提交都能稳稳接住。

即时编译JIT

发表于 2023-05-11 分类于 JVM

即时编译（Just-In-Time Compilation，简称JIT）是一种编译技术，它在代码即将首次执行时进行编译，因此得名“即时编译”。JIT是动态编译的一种特例。随着时间的发展，JIT的概念已经扩展，现在常被用来泛指动态编译；然而，狭义的JIT编译与更广泛的动态编译之间仍存在区别。动态编译（Dynamic Compilation）指的是在程序运行时进行编译，而静态编译（Static Compilation，也称事前编译，Ahead-Of-Time Compilation，简称AOT）则是在程序运行前完成编译。自适应动态编译（Adaptive Dynamic Compilation）也是一种动态编译技术，它先让程序以某种方式运行，收集信息后再进行编译，从而实现更高层次的优化。
